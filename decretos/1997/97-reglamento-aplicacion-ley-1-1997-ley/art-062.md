# Artículo 62

Para asegurar el aprovechamiento sostenible, no se podrá apear árboles de los que se extraen productos comerciales no maderables, como en el caso de, Biasa (Pygeum africanum) o árboles q_ue sirven de apoyo para plantas que producen especies no maderables; como el caso de, el Topotó (Pimienta negra).
